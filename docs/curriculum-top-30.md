# Security Studio — программа из 30 уроков

Каждый урок должен иметь теорию, уязвимый и исправленный пример, редактируемое задание, проверку отрицательных и положительных случаев, подсказки, сохранение кода/прогресса, журнал результата и сброс лаборатории. Проверка AI не заменяет детерминированный verifier.

## Обязательный полный цикл каждого урока

1. **Изучить**: цель, модель угроз, объяснение причины, последствия и короткий пример.
2. **Исследовать**: показать уязвимый фрагмент и отметить доверенные/недоверенные данные.
3. **Воспроизвести локально**: запускать только нужный учебный сценарий в изолированной лаборатории; фиксировать ожидаемый результат.
4. **Исправить**: редактировать код в Monaco, загрузить подсказку по запросу, сохранять в отдельную workspace урока.
5. **Проверить**: verifier на backend для конкретного lesson ID; у каждого verifier есть тесты уязвимого кода, исправленного кода, комментариев, смешанного безопасного/опасного кода и типичных обходов. AI не выставляет итоговый pass.
6. **Подтвердить**: показывать evidence и объяснять, что именно проверено; эвристический статический анализ не называть доказательством безопасности.
7. **Сохранить**: код, выбранную лабораторию, результаты, этапы урока и прогресс — по lesson ID.
8. **Сбросить/завершить**: очистить временные данные лаборатории, остановить контейнер, повторить проверку и отметить урок завершённым только после успешного verifier.

## Критерии готовности программы

- В каталоге ровно 30 уникальных ID; UI показывает все уроки и уровень/категорию.
- Выбор урока меняет содержание, примеры, verifier, контекст помощника и ключ прогресса.
- Каждый ID имеет уязвимый и исправленный пример и собственные позитивные/негативные тесты verifier.
- Сохранение одного урока не перезаписывает код другого.
- API отклоняет неизвестные ID, слишком большой код и неподдерживаемые действия.
- Запуск/остановка/статус лаборатории работают; сброс не оставляет учебные данные между сессиями.
- E2E проходит полный путь: выбрать урок → запустить лабораторию → изменить код → сохранить → проверить → увидеть evidence → перезагрузить страницу → восстановить состояние → остановить лабораторию.
- CI выполняет unit, API, frontend typecheck/build, E2E и smoke/security-тест лабораторного контейнера.

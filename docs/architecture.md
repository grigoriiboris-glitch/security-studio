# Архитектура Security Studio

## Компоненты

- Vue 3.5 + Vite — браузерное приложение.
- Element Plus — компоновка и элементы управления.
- Pinia — состояние урока, редактора и лаборатории.
- Monaco Editor — редактирование учебного фрагмента.
- @assistant-ui/vue — официальные Vue-примитивы; React-компоненты вручную не копируются.
- @assistant-ui/ai-sdk + AI SDK — runtime чата и потоковые сообщения.
- Fastify — локальный API и серверный прокси OpenCode Go.
- Единый образ security-labs — Juice Shop, NodeGoat и MongoDB; активна одна лаборатория.

## AI

Браузер -> POST /api/assistant/chat -> Fastify -> @ai-sdk/openai-compatible -> OpenCode Go -> MiMo-V2.6-Flash.

OPENCODE_GO_API_KEY читается только backend и не включается в переменные Vite. В запрос передаются User-Agent приложения и хеш ID чата в заголовке x-opencode-session. Backend сам выбирает системные инструкции по allowlist lessonId.

Документация: https://www.assistant-ui.com/docs/vue, https://www.assistant-ui.com/docs/vue/ai-sdk, https://opencode.ai/docs/en/go/.

## Безопасность и ограничения

- Backend по умолчанию слушает только 127.0.0.1:3001.
- Мутационные маршруты проверяют Origin, chat ограничен rate limit и размером контекста.
- Контроллер вызывает Docker через execFile, фиксированные аргументы и allowlist ID лабораторий, без произвольных shell-команд.
- Лаборатории работают в отдельной пользовательской bridge-сети без IP masquerading: это сохраняет публикацию портов на 127.0.0.1, но не даёт контейнерам обычный NAT-доступ в интернет. CI проверяет публикацию HTTP-портов и фактическую невозможность исходящего HTTPS-подключения.
- Контейнер не получает Docker socket, порт MongoDB не публикуется. SQLite Juice Shop и логи доступны на запись только через ограниченные tmpfs; статические учебные файлы вынесены отдельно и остаются неизменяемыми.
- Оценивание кода независимое от AI и основано на эвристиках статического анализа.
- SQLi demo разрешён только для активного Juice Shop, использует фиксированный loopback endpoint и не раскрывает токен сессии.

## Текущие ограничения MVP

1. Monaco пока редактирует демонстрационный фрагмент в браузере; он не записывается обратно в исходники учебной системы.
2. SQL checker — эвристика, не полноценный SQL-парсер и не доказательство безопасности произвольного проекта.
3. История диалога живёт в памяти браузера.
4. Реальный расход RAM нужно измерить на целевом компьютере и отрегулировать лимиты по результатам CI и локального прогона.

# Единый образ security-labs

Образ содержит:

- OWASP Juice Shop 20.3.0 на Node.js 22;
- OWASP NodeGoat на Node.js 12, зафиксированный Git commit;
- MongoDB 4.4 для NodeGoat.

NodeGoat использует старый MongoDB-драйвер, поэтому внутри единого контейнера используется MongoDB 4.4, как в upstream docker-compose проекта. Для Juice Shop используется Node.js 22. Версии и загрузки закреплены в Dockerfile; скачанные архивы проверяются SHA-256.

Сборка из корня репозитория:

    docker build -f labs/Dockerfile -t security-labs:dev labs

Backend использует один контейнер с фиксированным именем, запускает одну лабораторию за раз. В UI кнопка «Запустить пример SQLi» отправляет фиксированный запрос только на локальный `/rest/user/login` Juice Shop; произвольная цель и полезная нагрузка не принимаются, токен ответа не возвращается браузеру. HTTP-порты публикуются только на 127.0.0.1; порт MongoDB не публикуется. Для лабораторий используется отдельная bridge-сеть с отключённым IP masquerading: это позволяет публиковать локальные HTTP-порты без обычного исходящего NAT в интернет. CI отдельно проверяет доступность HTTP и невозможность исходящего HTTPS-подключения. Лимиты CPU/RAM/PID, no-new-privileges, сброшенные capabilities и read-only filesystem дополнительно ограничивают поверхность атаки. Docker socket не монтируется в лабораторию.

Обе системы намеренно уязвимы. Не публикуйте их в интернет.
